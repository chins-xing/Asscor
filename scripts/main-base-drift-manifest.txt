# ASSCOR 底座一致性：有意差异清单（双侧登记，v3 格式）
# ----------------------------------------------------------------------------
# 用途：`scripts/check-main-base-consistency.sh` 的**输入**。
#       裁定来源：用户 2026-09-13 裁定「乙」——
#         底座路径集合 减去 本清单 之后，main 与 ARC 必须逐字节相同；
#         清单内的差异视为**有意**，逐条核对，且**两侧都比对**。
#
# 格式： <登记 blob sha(ARC 侧 HEAD)>  <登记 blob sha(main 侧 BASE_REF) | ABSENT>  <路径>  # 理由
#   · 两侧都有的文件记 main 侧 blob sha；
#   · 只在 ARC 有的文件记字面量 ABSENT（表示「main 上不存在」）；
#   · 任一侧与登记不符都报红（ABSENT 变成"确实存在"也算不符）。
#
# ⚠️ 维护须知：
#   1. 本文件里的 ARC 侧 sha 是**提交相关**的。任何**改动底座文件**的提交之后，
#      都必须重跑 `scripts/check-main-base-consistency.sh` 并按输出更新 ARC 侧登记，
#      否则会报「[登记失效] … ARC侧(登记… 实际…)」。
#   2. **不要**把研究线专属路径写进来（它们在检查的 `EXCL` 负路径里，本来就排除在外）。
#      本清单只登记「**底座路径内**有意不同」的条目。
#   3. 新增一条时**必须**写理由（行尾 `# …`）——没有理由的登记等于没登记。
#
# 生成方式（下次更新时照此重跑）：
#   git diff --name-only main HEAD -- <底座路径…> <负路径…> | sort
#   然后对每条取 `git rev-parse HEAD:<路径>` 与 `git rev-parse main:<路径>`。
# ============================================================================
