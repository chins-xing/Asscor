# 多主机复杂拓扑审计 — 网络拓扑感知 T1–T11 实验

**日期**: 2026-08-16 | **版本**: v0.2.3 | **环境**: Containerlab v3 拓扑（18 节点 / 汇聚层环形 + ECMP / 12 主机 / 8 个子网以上）

## 一、测试环境（复杂度提升版）

```
s5720 ── 82580 ── r1 (核心, NAT+OSPF 默认宣告)
                 │
              edge0 (kernel)
                 │
        r1 ──┬── r2 ── host1/host2/host9
             ├── r3 ── host3/host4/host10
             ├── r4 ── host5/host6/host11
             └── r5 ── host7/host8/host12
  汇聚层环形冗余: r2─r3─r4─r5─r2 (4 条环链)
  多路径: 任意汇聚路由器到远端有 2-3 条等价路径 (ECMP 已确认 3 nexthop)
```

- 12 台主机分属 12 个独立 /24，跨 2-3 跳互联；12 台独立 mTLS 证书 + 身份绑定
- 基线：12 台同质（干净 ubuntu），SSAM 全 58.27，PRISM 全 43.7（Untrusted/collapsing）

## 二、实验矩阵与结果

| # | 实验 | 方法 | 观察结果 | 结论 |
|:-:|------|------|---------|------|
| T1 | 多跳网络 | host1→host8 跨 2-3 跳 vs host1→host2 直连 | 传播边不区分跳数（均 risk_transmission=0.3） | ❌ **无路径识别**：仅子网重叠判断可达性，多跳与直连等价 |
| T2 | 多路径 | ECMP 3 条等价路径（r2→host6 3 nexthop） | 传播边与路径数无关 | ❌ **多路径冗余不被感知**（风险传播不考虑路径冗余/数） |
| T3 | 环路 | 汇聚环 r2-r3-r4-r5-r2 + 冗余 | OSPF 稳定收敛、ping 全通、kernel 0 panic | ✅ 网络层稳定；ASSCOR 子网重叠图无环概念，不受影响 |
| T4 | 管理网污染 | 12 台共享 mgmt 172.20.20.0/24 | **每台 edges=11 全互达**（假传播） | ❌ **P1 确认**：管理网段混入拓扑 → 全互达假象 |
| T5 | 节点动态上下线 | host1 agent kill → 75s → 重启 | 身份绑定保留（指纹不变）、重新注册 accepted | ✅ **身份状态一致性良好**（绑定持久化 + 剪除修复生效） |
| T6 | 路由变化 | 断 r2-r3 环 → ECMP 3→2 | 网络冗余保持连通；**传播边不随路由变化** | ❌ 拓扑模型与真实路由状态脱节（时序不一致） |
| T7 | 服务迁移 | host1 身份迁移到 host9 位置（同证书） | 重新注册 accepted、指纹不变、子网更新 | ✅ 身份/拓扑解耦合理（身份随 host_id，拓扑随上报） |
| T8 | 单点失效 | stop r1（唯一核心+出口） | **edge0 与全网断开，12 agent 全部失联**，恢复后群发重连 | ❌ **无高可用设计**（kernel 单点 + 网络单点）；SRD 断连期停止 |
| T9 | 大量低风险节点 | 12 台干净基线 | 全互达 → 每台 11 条入边 → PRISM 全 43.7（prop_cap 封顶） | ❌ **无噪声抑制**：低风险节点也传播固定 0.3，节点越多噪声越重 |
| T10 | 少量关键节点 | host2 差配置 vs host3 无配置 | 作为传播源量相同（34 vs 33）；198 条边 risk_transmission **全固定 0.3** | ❌ **无风险聚焦**：传播不按源风险加权，关键节点风险无法放大 |
| T11 | 拓扑高度复杂 | 18 节点环+ECMP 全量评估 | 0 panic、185 心跳、评估周期正常、23 轮评估 | ⚠️ **简化能力过粗**：把复杂拓扑压成"同子网互达"二元图，丢失路径/跳数/环路/冗余结构 |

## 三、缺陷汇总（按严重度）

| 级别 | 缺陷 | 实验 | 影响 |
|:---:|------|:---:|------|
| **P1** | 管理网段污染扩散边（agent 上报含 mgmt 网段） | T4/T9 | 全互达假象 → O(n²) 假传播噪声，PRISM 分数失真 |
| **P1** | 无风险加权传播（risk_transmission 固定 0.3） | T10 | 关键节点风险无法聚焦，低风险噪声无法抑制（T9 同根） |
| **P1** | 拓扑模型无路径/跳数/可达性（仅子网重叠） | T1/T2/T6 | 多跳/多路径/路由变化均不感知，传播模型与真实网络脱节 |
| **P2** | 评估时序依赖（拓扑信息按上报顺序累积） | T11 | 同质主机首轮 edges 1→11 递增，PRISM 分数漂移 |
| **P2** | 无高可用/冗余感知（kernel+网络单点） | T8 | 核心失效 = 全网失联，SRD 停止 |
| **P3** | 传播边源/目标无角色或风险语义 | T9/T10 | 无法区分"关键资产"与"边缘主机"的传播权重 |

## 四、结论

1. **网络拓扑感知**：链路完整（采集→registry→SRD/PRISM 扩散边→Locator），但模型粒度停留在**子网重叠二元图**——T1-T11 中除 T3/T5/T7 外均暴露了该模型的局限。
2. **核心短板是传播模型**：固定风险系数 + 子网重叠 + 管理网污染，三者叠加使"风险传播"在真实复杂网络中失真（假传播、无聚焦、无抑制）。
3. **状态一致性**（T5/T7）：身份绑定与拓扑更新的持久化机制表现良好，是本次审计的亮点。
4. **健壮性**（T8/T11）：评估引擎稳定（0 panic），但系统级高可用缺失。

## 五、修复建议（优先级）

| 级别 | 建议 | 关联实验 |
|:---:|------|:---:|
| P1 | agent 过滤管理/虚拟网段（仅上报业务网段） | T4/T9 |
| P1 | 传播系数按源主机风险加权（如按 failed 检查数/分数归一化） | T9/T10 |
| P1 | 拓扑感知引入"可达性"（跳数/路径），SRD 边按真实可达性而非子网重叠 | T1/T2/T6 |
| P2 | 评估时统一拓扑快照（消除时序漂移） | T11 |
| P2 | kernel 双节点冗余或 agent 多 kernel 地址（高可用） | T8 |
| P3 | 主机角色/资产价值元数据（关键资产加权传播） | T10 |
