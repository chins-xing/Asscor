# ASSCOR 拓扑模型能力缺口全景（T1–T21 审计总结）

**日期**: 2026-08-16 | **版本**: v0.2.3 | **依据**: `TOPO_COMPLEX_AUDIT_T1_T11`、`TOPO_SEMANTIC_AUDIT_T12_T16`、`TOPO_DYNAMICS_AUDIT_T17_T21`

## 一、一句话结论

ASSCOR 的"网络拓扑感知"实际实现为**静态、无向、无权重、无生命周期的子网重叠图**：
> 两主机共享任一网段 → 判定互达 → 以固定系数 0.3 双向传播风险。

21 个实验（多跳/多路径/环路/污染/非对称/慢链路/ACL/安全域/节点下线/断链/抖动/并发）中，**传播边从未随真实网络发生任何变化**——引擎对网络"免疫"，但免疫的方式是**无视**。

## 二、能力缺口全景（按层）

### 1. 信息采集层（agent → kernel）

| 缺口 | 现状 | 证据 |
|------|------|------|
| 采集面过窄 | 仅 LocalIPs / Subnets / NetworkZone 三字段有值；`Gateways`/`Neighbors` 定义了但**未采集** | 代码审查（agent.go `collectNetworkInfo`） |
| 无链路属性 | 无延迟/带宽/链路类型上报 | T13：200ms 慢链路与直连传播等价 |
| 无安全边界 | 无 ACL/NAT/防火墙状态 | T14：被阻断主机对仍互达 |
| 无路径信息 | 无路由表/跳数/metric | T1/T16：多跳与直连等价，最短路径不被感知 |
| 管理网段污染 | 未过滤虚拟/管理网段 | T4：12 台共享 mgmt /24 → 全互达假传播 |

### 2. 拓扑表示层（topology registry / SRD 图）

| 缺口 | 现状 | 证据 |
|------|------|------|
| 无向 | 子网重叠为对称判定，非对称可达性不可表达 | T12：单向阻断后仍互达 |
| 无权重 | 边无成本/质量/风险语义 | T13 |
| 无方向性传播 | 风险双向等量传播 | T12 |
| 无域/区域语义 | NetworkZone 仅 internal/public/dmz 启发式，私有网段全 internal | T15：496 条记录全 internal |
| 无路径/跳数 | 图退化为"共享网段"二分 | T1/T2/T6/T16 |

### 3. 动态更新层

| 缺口 | 现状 | 证据 |
|------|------|------|
| **无注销/删除** | `RecordTopology` 仅 add/update，无 delete | T17：host3 下线后仍是传播源（残留） |
| 无链路状态更新 | 断链/收敛/抖动不影响传播边 | T18/T19/T20/T21 |
| 静态快照累积 | 拓扑按上报顺序累积，无事件驱动 | T11：首轮 edges 随评估顺序 1→11 |
| 时序依赖 | 同质主机分数依赖评估时刻拓扑完整度 | T11：host1 首轮 PRISM 58.27 vs 次轮 43.7 |

### 4. 风险传播模型层（PRISM/SRD）

| 缺口 | 现状 | 证据 |
|------|------|------|
| **固定传播系数** | `risk_transmission` 恒 0.3（198 条全同） | T10：关键节点与普通节点传播量相同（34 vs 33） |
| 无噪声抑制 | 低风险主机也传播 0.3，节点越多 O(n²) 假传播越重 | T9：12 台全互达 → 每台 11 条入边 |
| 无风险聚焦 | 传播不按源风险/资产价值加权 | T10 |
| 传播与网络状态脱节 | 传播边不随路由/链路/节点变化 | T6/T18-T21 |

### 5. 系统层

| 缺口 | 现状 | 证据 |
|------|------|------|
| 无高可用 | kernel 单点 + 网络单点（唯一核心/出口） | T8：r1 失效 → 全网失联 |
| ✅ 引擎稳定性（亮点） | 快速抖动/并发评估 0 panic | T20/T21 |
| ✅ 身份一致性（亮点） | 绑定持久化、服务迁移身份跟随 | T5/T7 |

## 三、缺口根因（三层归因）

1. **信息模型过窄**：拓扑 = 主机 → 子网列表（`map[string][]string`），一个 IP 层的静态快照，未建模边（link）、方向、权重、域、生命周期。
2. **传播模型过简**：`subnet 重叠 → 固定 0.3` 是唯一规则，无风险加权、无方向、无衰减（跳数）、无抑制。
3. **生命周期缺失**：无 topology 事件（注册/更新/注销/链路 up/down），SRD 图只在每次上报时被动覆盖。

## 四、修复路线图（按优先级）

| 优先级 | 能力 | 实验依据 | 方向 |
|:---:|------|:---:|------|
| P0 | 拓扑生命周期（注销/链路事件） | T17/T18 | topology registry 增加 delete/event；节点超时或心跳丢失时清除/标记其边 |
| P0 | 管理网段过滤 | T4/T9 | agent 或 kernel 过滤 RFC1918 管理/虚拟网段（或网段白名单） |
| P1 | 风险加权传播 | T9/T10 | `risk_transmission` 按源主机风险（failed 检查/分数）归一化；低风险源衰减 |
| P1 | 可达性建模（非子网重叠） | T1/T2/T6/T12/T14/T16 | 引入真实可达性（路由感知：跳数/metric/ACL 状态）替换"共享网段"判定 |
| P1 | 评估时序统一 | T11 | 评估时取统一拓扑快照 |
| P2 | 链路属性上报 | T13 | agent 采集链路质量（可选，成本高） |
| P2 | 安全域/资产价值元数据 | T15/T10 | zone 细分 + 关键资产标记，传播按域/价值加权 |
| P2 | 高可用 | T8 | kernel 多实例或 agent 多 kernel 地址 |

## 五、能力成熟度评估

| 维度 | 成熟度 | 说明 |
|------|:---:|------|
| 身份与状态一致性 | ★★★★☆ | 绑定持久化/迁移/重连机制扎实（T5/T7） |
| 引擎稳定性 | ★★★★☆ | 复杂拓扑+快速变化 0 panic（T3/T20/T21） |
| 拓扑信息采集 | ★★☆☆☆ | 链路完整但采集面窄、含污染（T4） |
| 拓扑表示 | ★☆☆☆☆ | 无向无权重子网重叠图 |
| 动态更新 | ★☆☆☆☆ | 无注销、无链路事件（T17/T18） |
| 风险传播模型 | ★☆☆☆☆ | 固定系数、无方向、无加权（T9/T10/T12） |
| 整体拓扑感知 | **★☆☆☆☆** | 仅剩"子网重叠"一条信息，21 个实验传播边零变化 |

> **核心判断**：当前拓扑模型可作为**占位实现**（证明采集→注册→扩散链路可行），但距离"网络拓扑感知"的产品级能力，缺口集中在**图模型表达力（表示层）**与**生命周期（动态层）**——这两层不补，风险传播在真实网络中必然失真。
