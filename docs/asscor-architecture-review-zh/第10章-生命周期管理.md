# 第 10 章 — 生命周期管理

安全评估平台必须初始化服务、协调插件、管理运行时资源、执行评估并最终优雅关闭。Asscor 引入了结构化的生命周期管理机制。

运行时状态序列：创建 → 初始化 → 启动 → 运行 → 停止 → 已停止。每个受管理组件遵循相同生命周期：构造 → 初始化 → 启动 → 运行 → 停止 → 销毁。

启动过程遵循确定性顺序——加载配置 → 初始化日志器 → 创建内核 → 注册核心服务 → 加载插件 → 初始化提供者 → 启动调度器 → 启动评估运行时。任何组件不应在其依赖可用之前开始执行。

优雅关闭以启动的相反顺序进行——停止评估 → 停止调度器 → 卸载插件 → 释放服务 → 关闭内核。故障不应立即终止运行时——生命周期管理器可选择重试初始化、隔离故障组件或继续降级运行。

每个受管理组件应暴露其运行状态——健康、降级、不可用、已停止。生命周期转换自然生成事件，其他组件可订阅而不引入紧密耦合。内核应与接口交互而非具体实现。

未来生命周期能力可包括热插件重载、滚动评估更新、分布式运行时协调、检查点恢复、运行时快照。
