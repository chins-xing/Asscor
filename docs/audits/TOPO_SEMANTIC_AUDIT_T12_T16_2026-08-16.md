# 拓扑语义审计 — T12–T16 实验（第一批）

**日期**: 2026-08-16 | **版本**: v0.2.3 | **环境**: Containerlab v3（18 节点 / 环形 + ECMP / 12 主机）

## 实验设计与结果

| # | 实验 | 网络层操作与效果 | ASSCOR 拓扑感知表现 |
|:-:|------|----------------|---------------------|
| T12 | 非对称可达性 | r2 `FORWARD DROP -s 10.10.1.0/24`：host1→host8 完全不可达（0 received）；反向请求可达但应答被同规则阻断（同样丢包）——真实的非对称/单向阻断 | ❌ **无方向概念**：传播边为无向子网重叠，单向阻断后 host1↔host8 仍互达（edges 11） |
| T13 | 不同链路类型 | r2–r3 环链路 `tc netem delay 200ms`：host1→host4 实测 **200.2ms** vs 本地 host1→host2 **0.08ms**（2500 倍差异） | ❌ **无链路属性**：无延迟/带宽/链路质量概念，慢链路与直连传播等价（均 risk_transmission=0.3） |
| T14 | NAT/Firewall/ACL | r2 ACL `FORWARD DROP -s 10.10.1.0/24 -d 10.10.8.0/24`：host1→host8 被阻断不通；host1→host5 正常（0.13ms） | ❌ **无视 ACL**：被阻断的主机对在拓扑中仍互达（edges 11），安全边界不被建模 |
| T15 | 跨安全域 | 检查 zone 机制：kernel 496 条 network info **全部 `zone=internal`**（inferZone 私有 IP 一律 internal） | ❌ **无域隔离**：12 台无任何域区分；传播跨"域"与域内完全等价；kernel 无域间信任/阻断概念 |
| T16 | 非最短路径 | r2→10.10.8.0/24 走最短路径（r2–r5 环直连，metric 20）；绕行路径（r2→r1→r5 / r2→r3→r4→r5）存在但未使用 | ❌ **无路径模型**：不感知实际转发路径、跳数、metric；传播与"哪条路径被用"无关 |

## 汇总数据

- T12–T16 全部网络操作期间触发评估：**12 台主机传播边全部保持 11（全互达），分数 58.27、PRISM 43.62 无任何变化**
- 结论：**拓扑语义的五个维度（方向/链路质量/安全边界/安全域/路径）ASSCOR 均不建模**——传播模型仅有的信息是"子网重叠"

## 缺陷汇总

| 级别 | 缺陷 | 实验 |
|:---:|------|:---:|
| P1 | 传播边无方向（非对称可达性/单向链路被忽略） | T12 |
| P1 | 无链路属性（延迟/带宽/质量）参与风险计算 | T13 |
| P1 | 安全边界（ACL/NAT/防火墙）不建模，被阻断主机对仍互达传播 | T14 |
| P1 | 无安全域概念，跨域与域内传播等价 | T15 |
| P2 | 无路径模型（跳数/metric/实际转发路径） | T16 |

## 结论

拓扑语义层目前只有"子网重叠"这一条信息。T12–T16 表明：真实网络的非对称性、链路差异、安全边界、域隔离、路径选择**全部丢失**。风险传播基于"共享网段"的假设在存在这些语义的真实网络中会产生**显著误判**（例如：被防火墙完全隔离的主机对之间仍在传播 0.3 风险）。
