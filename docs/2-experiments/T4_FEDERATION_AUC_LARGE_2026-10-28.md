# T4 联邦 AUC 大规模实验：37 主机 × 3 轮 ACL（2026-10-28）

> 上一轮（870 对、2 个负样本）只是烟测。这一轮把**全部数据面 asc 主机**拉进来，
> 用**三轮递增 ACL**把负样本提到 508，再对比 V1/V2。

## 1. 规模与主机

| 类别 | 数量 | 说明 |
|---|---|---|
| T4 agent | 30（CT 940-969） | 4 个 vnet 轮转，dual NIC（mgmt + data） |
| 旧实验域主机 | 6（CT 921-925、927） | 数据面 vnetA/B/C/D；925 双归属 |
| 路由器 | 1（CT 920） | 4 个 vnet 接口 + 管理口，转发者 |
| 合计真值端点 | **37** | 37×36 = **1332 对/轮** |
| 排除 | CT 911-913 | 仅管理网（ACL 不影响），不参与数据面真值 |

节点 kernel 3 台（930-932）+ 主 kernel（910）参与评分与合并图（40 主机）。

## 2. 三轮 ACL（920 forward 链，drop 在 accept 之前）

| 轮 | 规则 | 负样本（实测） |
|---|---|---|
| R1 | A→B drop | 100（+37 其他不可达） |
| R2 | A→B、C→D | 164（+37） |
| R3 | A→B、C→D、B→C | 244（+37） |

## 3. 结果

| 轮 | 对数 | 负样本 | **V2 合并图** | **V1 单节点视角** |
|---|---|---|---|---|
| R1 | 1332 | 100 | **0.930** | 0.546 |
| R2 | 1332 | 164 | **0.914** | 0.542 |
| R3 | 1332 | 244 | **0.879** | 0.548 |
| **合并（并集）** | **3996** | **508** | **0.912**（三 profile 同值；ENS 0.912） | **0.545** |

**delta（V2 − V1）= +0.367**。

三套 profile（nk1 0.80/5/rss、nk2 0.65/7/max、nk3 0.50/9/linear）在二元可达性真值上
AUC **完全一致**（差异 <0.001）——再次说明：**decay/depth/aggregation 影响的是风险排序，
不是可达性判定**。

## 4. 解读

1. **联邦合并带来 +0.37 AUC**：单节点图只能看到自己 10 台、且没有共享路由器，
   跨 vnet 的 87% 阳性对被判 0 分（假阴性），AUC 被压到 0.55。
2. **V2 随负样本增加而下降（0.930→0.879）**：R3 里 B→C 的 deny 与 A→B/C→D 叠加，
   模型对**多规则叠加**的判定有少量错误（负样本增加暴露边界）；pooled 0.912。
3. **路由器策略是跨 vnet 判定的关键事实**：修复"策略地址带主机位"（`172.22.10.1/24`）
   后才从 0.65 提升到 0.91——**策略事实的地址形式本身就是正确性问题**。
4. **911-913 只能管理网**：它们不参与数据面真值（否则全是恒真阳性），这本身是
   "容器网络异构"的说明。

## 5. 复现

- 汇总：`t4-auc-large-summary-20261028.txt`
- 逐对：`t4-auc-large-pooled-20261028.csv`（3996 行：round/src/dst/truth/v2_nk1/v2_nk2/v2_nk3/ensemble/v1）
- 工具：`cmd/fevauc`（与 `topology.HostReachable` 同 API）
- 图导出：主 kernel `GET /federation/export`、节点报告 `GET /federation/nodes`

## 6. 结论

**在同一张多域网络、508 个真实不可达对上，联邦合并把 AUC 从 0.545 提到 0.912（+0.367）。**
差距几乎全部来自"单节点看不到跨域主机与共享路由器"；这也量化了 v0.2 图事实上报的必要性。
