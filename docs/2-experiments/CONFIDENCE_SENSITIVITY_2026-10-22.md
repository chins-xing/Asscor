## 1. 固定夹具

全部参数显式固定，唯一变量是每个失败检查的观测可信度 `c`：

```go
weights      = ssam.DefaultWeights              // attack_surface 35, business_continuity 25,
                                                // operation_trust 25, resilience 15
policy       = {Enabled:true, Default:1.0, Floor:0.05}
checks       = [
  {AS-001, attack_surface,   Passed:false, Delta:-30, Confidence:c},
  {OT-001, operation_trust,  Passed:false, Delta:-20, Confidence:c},
]
SPCScore     = 1.0
ThreatCoeff  = 1.0
Threshold    = 80
formula      = ssam_v2.0
```

计分口径（与生产插件路径同一个 `ssam-lib` 实现）：

```
E_d   = Σ |δ_i|·c_i
score_d = max(0, 100 − E_d)
σ_d   = sqrt(Σ |δ_i|²·c_i·(1−c_i))
Total = 0.5·(Σ w_d·score_d / Σ w_d) + 0.3·100·SPC + 0.2·100·Threat
σ_final = 0.5 · sqrt(Σ (w_d·σ_d)²) / Σ w_d
[Lower95, Upper95] = [Total − 1.96·σ_final, Total + 1.96·σ_final]，仅下界钳到 0
EvidenceConfidence = Σ(|δ_i|·c_i) / Σ|δ_i|
```

## 3. 怎么读这张表

1. **`c` 越低，点估计越高、σ 越大**：可信度低 ⇒ 期望扣分 `Σ|δ|·c` 变小 ⇒ 域分/总分更高，
   但不确定度 `Σ|δ|²·c(1−c)` 变大。这是「信息不足时分数被拉回、同时区间变宽」的预期形状，
   不是精度提升。
2. **`σ` 在扫描区间端点最大、在 `c=1.0` 归零**：`c(1−c)` 在 `c=0.5` 取最大；`c=1.0` 时该模型
   认为观测无随机性，区间退化为 `[score, score]`。
3. **`EvidenceConfidence` 在这条夹具上恰好等于 `c`**（两个失败项同 `c`，且
   `Σ|δ|·c / Σ|δ| = c`）。换夹具（不同 `c` 混合）就不再等于单一 `c`。
4. **`Upper95` 可以大于 100**（`c=0.5` 时 103.0376）：这是审计 I-12 的**有意行为**——只钳下界，
   保证点估计不落在区间外；`Total` 本身在 `threat_coeff>1` 等情形也可超过 100。
5. **`Threshold=80` 在这张表上不产生拒绝**：所有行 `FinalScore ≥ 80`，且即使打开
   `accept_by_lower_bound`，除 `c=1.0` 外下界也都 ≥ 82。要观察保守判定差异，需要更低分/更高
   σ 的夹具（见 B-2 单测 `TestAcceptByLowerBound*`），本表不用于该结论。

## 4. 明确不能由本文件得出的结论

- 不能声称「默认来源置信表已用数据标定」或「0.90/0.80/1.0 是最优值」。
- 不能声称 95% 区间有名义覆盖率；它不是频率学派/贝叶斯意义上的有效后验区间。
- 不能把本表当作「敏感性分析覆盖了真实资产分布」的证据：只有一条合成夹具、两个域、两个失败项。
- 不能由本表推断 `[confidence.source]` / `[confidence.domain]` 表的合理性——本表扫描的是
  **单个检查的观测可信度 `c`**，来源/域表通过解析器映射成 `c` 后才进入同一套公式。
