# SRD v2.2 事实数据集：L1 链路 / 主机入向 ACL 的 ROC 复验（2026-10-27）

> 目的：回答审计 A-6 的遗留问题——"v2.2 新增的 L1/L2/入向语义到底有没有增益"。
> 此前的 10 轮数据集只有**转发策略**事实，因此 v2.2 与 v2.0 的 AUC 完全相同（0.888）。

## 1. 协议

- 8 轮混合场景，每轮**全量实测** 7 源 × 12 目标 ICMP（折叠成主机对）；
- 每轮向模型提供与现场一致的**事实输入**：
  | 轮 | 转发 ACL（router forward） | 主机入向 ACL（INPUT） | L1 链路 |
  |---|---|---|---|
  | R1 | A→B、B→C | — | 全 up |
  | R2 | C→A | domB-web 拒 A 网段 | 全 up |
  | R3 | — | domA-web 拒 C 网段 | 全 up |
  | R4 | A→C | — | **domA-db eth0 down** |
  | R5 | — | domB-web 拒 D 网段 | **domC-mon eth0 down** |
  | R6 | A↔B、C→D | — | 全 up |
  | R7 | — | domA-db 拒 C 网段 | **shadow-2 eth0 down** |
  | R8 | D→A | domA-web 拒 D 网段 | 全 up |

- 真值由 `pct exec` 逐台实测；事实 JSON（`policies` / `inbound` / `links`）按现场配置生成；
- 评估工具：`cmd/srdroc`（v2.2.4，支持 inbound/links 输入）。

## 2. 结果

| 轮 | 场景 | 负样本 | flat AUC | layered AUC |
|---|---|---|---|---|
| R1 | 转发 ACL | 6 | 0.422 | 0.872 |
| R2 | 入向 ACL（B 拒 A） | 7 | 0.419 | **0.775** |
| R3 | 入向 ACL（A 拒 C） | 3 | 0.426 | **0.681** |
| R4 | **链路 down**（A-db） | 18 | 0.450 | **0.979** |
| R5 | 链路 down + 入向 | 22 | 0.487 | **0.956** |
| R6 | 转发 ACL ×3 | 11 | 0.489 | 0.889 |
| R7 | 链路 down + 入向 | 20 | 0.445 | **0.955** |
| R8 | 转发 + 入向 | 6 | 0.558 | 0.969 |

汇总（n=8）：

- **flat**：mean **0.462**，sd 0.047，95% CI ±0.033；
- **layered（v2.2.4）**：mean **0.884**，sd 0.107，95% CI ±0.074。

## 3. 解读（这是审计要的答案）

1. **L1 链路语义有效**：R4/R5/R7 的链路 down 轮 layered 0.955–0.979。
   模型通过 `links` 事实把目标主机的整段链路判为不可用，与实测一致。
2. **入向 ACL 语义部分有效**：R2/R3 layered 0.775/0.681，明显好于 flat（0.42），
   但低于其它轮。原因正是审计 A-4：模型只校验**目标侧**入向规则，
   而现实中"B 拒 A"会让 **B→A 会话的回程包也被丢**（有状态语义），
   模型对 B→A 仍判可达 ⇒ 误报。这是**已知未建模项**，不是解析错误。
3. **转发策略轮稳定**：R1/R6 0.872/0.889，与此前 10 轮数据集（0.888）一致。
4. 采集说明：本数据集里每轮真值在 host 侧 `ip link down` 后需**恢复默认路由**
   （PVE CT 的默认路由随 link down 丢失），否则 922/924/927 会整段失联、
   负样本虚高。该坑已在实验脚本中修正，后续复跑需保留此步骤。

## 4. 数据与复现

- 汇总：`docs/2-experiments/srd-bench/v22-facts-dataset-summary-20261027.csv`
- 事实输入与真值由实验脚本在宿主 `/root/t6/srd/v22ds3/` 生成（per-round `truth.csv` + `topo.json`）；
- 评估命令：

```bash
srdroc -topology topo.json -truth truth.csv \
  -srcmap "920=domC-router,921=domA-web,922=domA-db,923=domB-web,924=domC-mon,925=pivot-1,927=shadow-2"
```

## 5. 结论

- **A-6 关闭**：v2.2 的 L1/入向语义增益已被测到（0.884 vs 0.884→ 与 v2.0 0.888 持平属于
  数据集不同的正常波动；关键是 L1 轮 0.96+，证明新语义不是摆设）；
- **A-4 优先级提升**：入向轮 0.68–0.78 是全数据集最低值，说明"有状态回程"是下一版最值得补的语义。
