# 第 13 章 — 调度器与任务管理

持续安全评估要求的远不止单次执行。Asscor 引入运行时调度器负责在整个系统生命周期中协调评估任务。

每个可执行活动被表示为一个任务，包含 ID、名称、类型、状态、调度、优先级、重试策略和元数据。每个任务遵循明确定义的生命周期：创建 → 排队 → 调度 → 运行 → 完成 → 归档。

不同工作负载需要不同调度策略——周期性（每5分钟：主机评估）、事件驱动（配置变更 → 评估）、手动、一次性。任务优先级：关键 → 高 → 正常 → 低。调度器应管理工作池、并发限制、资源分配和队列管理。

故障不应立即终止执行。典型重试策略包括固定重试、指数退避、限制重试次数和手动恢复。调度器与事件总线自然集成——使反应式评估成为可能而非固定轮询。调度器应暴露运行指标：排队任务、运行中任务、失败任务、重试计数、执行延迟。
