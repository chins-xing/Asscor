# 第 9 章 — 内核架构

内核是 Asscor 运行时的中央协调器，不直接执行安全评估——它提供使所有系统组件作为统一平台运行的执行环境。其主要职责是编排而非推理。

内核应仅负责基础设施关注点：运行时初始化、生命周期管理、依赖协调、服务注册表、事件分发、调度器启动、配置加载、健康监控。内核永远不应实现评估规则。

启动序列：加载配置 → 创建运行时上下文 → 初始化内核 → 注册服务 → 加载插件 → 解析依赖 → 启动调度器 → 启动评估运行时。

内核通过稳定接口暴露基础设施服务：注册表、事件总线、日志器、调度器、配置、指标、健康检查。内核拥有执行权——组件不控制内核。内核应该比系统其他部分更慢地演进。

一个逐渐显现的架构风险：内核可能在逐步积累来自更高层次的职责——评估逻辑、插件业务规则、策略评估、报告生成。如果这些职责进入内核，它成为"God Object"，显著降低了可维护性。建议的内核边界仅应包含运行时基础设施——其他一切应留在内核之外。
