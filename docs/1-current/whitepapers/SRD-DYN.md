## 0. 为什么必须分叉

原 SRD 的核心问题不是公式不够多，而是**“动力学”三个字没有数学所指**：

- 有效状态只有一个标量 `PrismScore`，四态向量是它的确定性函数，不是独立状态；
- 时间演化是“固定先验马尔可夫 + 静态快照传播”，没有统一时间步、没有反馈闭环；
- 债务恢复即清零，没有记忆；传播只做一轮，没有级联收敛；
- 置信度是输出熵，不是状态估计；参数是专家常数，没有辨识与预测校验。

因此原 SRD 可以被称为“拓扑感知的静态风险折扣器”，但不能被称为动力学系统。
SRD‑DYN 的目标是让“动力学”满足可检验的数学约束，而不是换一套术语。

---

## 1. “动力学”的判定标准

SRD‑DYN 采用以下六条作为**准入条件**（缺一不可）：

| 编号 | 条件 | 可检验含义 |
|---|---|---|
| D1 | **独立状态向量** | 至少 3 个不可由单一分数互相推出的状态分量 |
| D2 | **显式演化算子** | 存在 `dx/dt = F(x,u,t;θ)` 或离散映射 `x_{k+1}=F(x_k,u_k;θ)`，且非平凡状态下导数非零 |
| D3 | **记忆** | 当前状态携带历史；输入撤销后不会瞬间回到初始值 |
| D4 | **反馈** | 至少一个系数依赖状态本身（正反馈或负反馈），而非固定常数 |
| D5 | **观测与状态分离** | 观测模型 `y=h(x)+噪声` 与状态演化分离；置信度来自后验不确定性 |
| D6 | **可证伪预测** | 能对未参与拟合的时间段/干预给出预测，并用 proper scoring rule 评分 |

> 只满足 D2 的“分数随时间衰减”仍不是动力学；必须同时满足 D1/D3/D4/D5/D6。

## 2. 状态空间

对主机 `i`，定义状态向量：

\[
x_i(t)=\big(s_i(t),\, d_i(t),\, c_i(t),\, h_i(t)\big)
\]

| 分量 | 含义 | 取值范围 | 单位 | 是否直接观测 |
|---|---|---|---|---|
| `s_i` | 安全态势/健康度（越高越好） | `[0,1]` | 无量纲 | 是（带噪声） |
| `d_i` | 累积退化债务（失败历史） | `[0,∞)` | 失败·时间（归一化） | 否 |
| `c_i` | 系统性/级联负载 | `[0,∞)` | 风险负载（归一化） | 否 |
| `h_i` | 滞回/塌缩倾向（慢变量） | `[0,1]` | 无量纲 | 否 |

关键约束：

1. **`d_i` 不是 `s_i` 的函数**：同样的 `s_i` 可以对应“刚失败一次”与“反复失败三个月”两种完全不同的未来；
2. **`c_i` 不是拓扑静态分数**：它由邻居状态随时间注入并衰减；
3. **`h_i` 是慢变量**：它让系统在压力撤除后仍可能停留在低态势，形成滞回；
4. 四态语义（正常/关注/危险/塌缩）由 `(s,d,c,h)` 的联合区域定义，而不是由单分数阈值切分。

## 3. 连续时间演化

### 3.1 漂移方程

\[
\begin{aligned}
\dot s_i &= \rho_i(1-s_i) - \alpha_i d_i - \beta_i c_i - \gamma_i u_i - \eta_i h_i d_i \\
\dot d_i &= (1-s_i)u_i + \zeta_i u_i - \delta_i d_i \\
\dot c_i &= \lambda_i \sum_j A_{ij}\,\phi(s_j) - \nu_i c_i \\
\dot h_i &= \frac{1}{\tau_i}\big(H(s_i)-h_i\big)
\end{aligned}
\]

其中：

- `u_i(t) ≥ 0`：失败/攻击事件的强度率（由检查项、告警、观测映射而来）；
- `ρ_i`：自愈/恢复速率；`α_i,β_i`：债务与级联对态势的压制；
- `γ_i`：事件即时冲击；`η_i`：塌缩正反馈强度；
- `δ_i`：债务自然衰减；`ζ_i`：事件直接增加债务的系数；
- `λ_i`：邻居风险注入强度；`A_ij∈[0,1]`：有向耦合权重；
- `φ(s_j)=1-s_j`（或单调递减饱和函数）：邻居越不健康，注入越大；
- `ν_i`：级联负载衰减；
- `H(s)=1/(1+\exp((s-\theta_i)/\epsilon_i))`：低态势触发的塌缩倾向；`τ_i` 为滞回时间常数。

### 3.2 事件跳变（混合系统）

连续漂移不足以表达“检查失败/攻击成功”这类离散事件。SRD‑DYN 明确采用**混合系统**：

在事件 `e=(i,t_e,w_e)` 到达时：

\[
s_i \leftarrow \max(0, s_i-\gamma_i w_e),\qquad
d_i \leftarrow d_i+\zeta_i w_e
\]

事件之间按第 3.1 节演化。这样，“事件频率”与“事件强度”都进入状态，而不是只改一个静态分数。

### 3.3 平衡点与稳定性

令 `\dot x=0` 得到平衡点 `x*`。在 `x*` 处线性化：

\[
J_i=\left.\frac{\partial F_i}{\partial x_i}\right|_{x^*}
\]

要求：

- 报告 `J_i` 的特征值实部；存在稳定平衡点（全部 `<0`）或明确标注极限环/多稳态；
- 对 `η_i` 或 `λ_i` 做延拓，检测**鞍结分岔**（两个平衡点碰撞消失）；
- 若模型无法产生任何非平凡平衡点/分岔，则不满足 D4，不能称为动力学。

### 3.4 滞回

`h_i` 的慢时间尺度 `τ_i` 使系统具有路径依赖：

- 压力上升时 `h` 上升，压低 `s`；
- 压力撤除后 `h` 缓慢下降，`s` 不会立即恢复；
- 有效塌缩阈值因此不是单一常数，而是由 `h` 调制的动态阈值。

验收时必须展示：同一 `s` 在“上升路径”和“下降路径”上对应不同的 `h` 与不同的未来轨迹。

## 4. 观测模型与状态估计

### 4.1 观测方程

只有 `s_i` 可被直接观测（来自检查/评估），且带噪声：

\[
y_{i,k}=s_i(t_k)+\varepsilon_{i,k},\qquad \varepsilon_{i,k}\sim\mathcal N(0,R_i)
\]

`d_i,c_i,h_i` 为隐状态。

### 4.2 滤波

离散化后使用 EKF/UKF（v0.0.1 至少 EKF）：

\[
\begin{aligned}
x_{k+1}&=f(x_k,u_k;\theta)+w_k, & w_k&\sim\mathcal N(0,Q)\\
y_k&=h(x_k)+v_k, & v_k&\sim\mathcal N(0,R)\\
\hat x_k^-&=f(\hat x_{k-1},u_{k-1};\theta)\\
P_k^-&=F_kP_{k-1}F_k^\top+Q\\
K_k&=P_k^-H_k^\top(H_kP_k^-H_k^\top+R)^{-1}\\
\hat x_k&=\hat x_k^-+K_k(y_k-h(\hat x_k^-))\\
P_k&=(I-K_kH_k)P_k^-
\end{aligned}
\]

### 4.3 置信度定义

\[
\mathrm{Conf}_i = 1-\frac{\operatorname{tr}(P_i)}{\operatorname{tr}(P_i)+\kappa}
\]

或直接输出 `P_i` 的对角线/95% 可信区间。**禁止**再用输出状态向量的熵冒充“预测置信度”：
熵只说明分布集中，不说明估计是否正确。

## 5. 耦合与系统性风险

### 5.1 传播使用动态态势

邻居注入项使用**当前滤波后的 `s_j`**，不是静态 `SSAMScore`：

\[
\dot c_i = \lambda_i\sum_j A_{ij}(1-s_j)-\nu_i c_i
\]

因此，一台已经塌缩的主机 `s_j≈0` 会向邻居注入接近 `λ_i` 的负载；完好主机 `s_j≈1` 注入接近 0。风险会随级联被放大，而不是“静态分数广播”。

### 5.2 闭环求解

不再做“一轮遍历就输出”。v0.0.1 允许两种实现：

1. **时间积分**：与第 3 节同一 `Δt` 推进到观测时刻；
2. **不动点迭代**：在准稳态假设下迭代 `c ← λAφ(s(c))` 至收敛，并报告残差与迭代次数。

禁止把“单趟快照”称为系统性传播。

### 5.3 耦合权重

`A_ij` 与 `λ_i` 是待辨识参数（见第 8 节），不是永久硬编码常量。至少支持：

- 先验配置（拓扑/资产关键度）；
- 由历史事件/故障共现估计；
- 参数不确定性传播到 `c_i` 的置信区间。

## 6. 塌缩、多稳态与数值实现

### 6.1 塌缩不是“扣分项”

原 SRD 的 `(1-CollapseModifier)` 与 `sqrt(n)` 是对静态分数的后处理；SRD‑DYN 把塌缩定义为**状态空间中的低态势吸引域**：

- `η_i h_i d_i` 正反馈把 `s_i` 拉向低值；
- `h_i` 的慢变量制造滞回；
- 在参数区间内可出现两个稳定平衡点（健康态/塌缩态）。

### 6.2 离散化

统一时间步 `Δt`，要求：

- `Δt ≤ 0.1 · min(τ_s,τ_d,τ_c,τ_h)`；
- 使用 RK4 或半隐式积分；对 `d,c` 做非负投影；
- 事件按时间顺序处理，事件时刻可细分步；
- 输出 `Δt`、积分器、步数，保证可复现。

### 6.3 数值验收

- 同一输入、同一 `Δt` 下结果逐位可复现（固定浮点顺序）；
- `Δt` 减半后轨迹差 `<1e-3`（相对）；
- 无非物理负值/NaN/Inf；
- 长时间积分不发散；若发散，必须显式报错而非截断伪装正常。

## 7. 参数、可辨识性与敏感性

### 7.1 参数集

\[
\theta_i=\{\rho_i,\alpha_i,\beta_i,\gamma_i,\eta_i,\zeta_i,\delta_i,\lambda_i,\nu_i,\tau_i,\theta_i,\epsilon_i\}
\]

每个参数必须登记：物理含义、单位、先验范围、来源（专家/拟合/文献）、是否可辨识。

### 7.2 可辨识性

- 用 Fisher 信息矩阵 `I(θ)` 或剖面似然检查弱可辨识参数；
- 对不可辨识组合（如 `α` 与 `β` 同时缩放）必须固定其一或加正则，并在文档中说明；
- 报告参数估计的置信区间，而不是只给点值。

### 7.3 敏感性

- 至少做 one-at-a-time 与 Sobol 全局敏感性；
- 报告对 `s(T)`、塌缩时间、`c(T)` 的敏感度排序；
- 关键结论不能依赖未做敏感性分析的单个常数。

### 7.4 参数来源

禁止再把 `DebtNormDays=1500` 这类无现实对应的常数直接当真理。v0.0.1 要求：

- 每个常数有量纲/现实锚点；
- 用合成数据做参数回收（parameter recovery）：生成 `θ*` → 拟合 → 检查能否恢复；
- 用真实事件序列做校准，报告残差。

## 8. 验证与可证伪性

### 8.1 数据切分

- 时间序列按时间切分（不得随机打乱）；
- 训练/验证/测试分离；测试段不参与调参；
- 报告多步预测（h-step）而非只报一步。

### 8.2 指标

| 目标 | 指标 |
|---|---|
| 态势预测 | RMSE / MAE / CRPS |
| 塌缩二分类 | ROC-AUC / PR-AUC / Brier |
| 概率校准 | 校准曲线、ECE、intercept/slope |
| 级联预测 | 邻居后续恶化的命中率/提前量 |
| 干预预测 | 反事实轨迹误差 |

### 8.3 基线

至少对比：

1. 静态 SRD‑v0.2.3 分数；
2. 固定先验马尔可夫；
3. 持久性基线（`s_{t+1}=s_t`）；
4. 无耦合消融（`λ=0`）；
5. 无记忆消融（`δ→∞`）。

**若 SRD‑DYN 在时间外测试集上打不过持久性基线，动力学宣称不成立。**

### 8.4 可证伪承诺

在 v0.0.1 发布前预注册：

- 预测目标、时间跨度、评价指标、通过阈值；
- 失败条件（例如 AUC 提升 `<0.03` 或 CRPS 不改善）；
- 所有消融与随机种子。

## 9. 与原 SRD 的缺陷对应

| 原缺陷 | SRD‑DYN 的处理 | 验收 |
|---|---|---|
| 单标量状态 | 四维独立状态 `(s,d,c,h)` | D1 |
| 无滞回、阈值抖动 | 慢变量 `h` + 动态阈值 | D3/D4 |
| 塌缩项语义矛盾 | 正反馈/吸引域替代 `sqrt(n)` 后处理 | 6.1 |
| 债务恢复硬清零 | `d` 带衰减 `δ` 与事件累积 | D3 |
| RiskVelocity 未接线 | 直接输出 `\dot x`（含 `\dot s`） | D2 |
| 时间尺度混杂 | 统一 `Δt`、显式时间常数 | 6.2 |
| 固定先验马尔可夫 | 观测驱动的连续/混合演化 + 滤波 | D5 |
| 传播用静态分数 | 用滤波后 `s_j` | 5.1 |
| 单趟快照 | 时间积分/不动点迭代 | 5.2 |
| λ 静态常量 | 参数化 + 可辨识/敏感性 | 7 |
| 置信度=熵 | 后验协方差/可信区间 | 4.3 |
| 参数无辨识 | Fisher/剖面似然/参数回收 | 7.2 |
| AUC=1.0 误用 | 时间外测试 + proper scoring | 8 |

## 10. 实现契约（v0.0.1）

- 包/产物命名：`srd-dyn`；文档名 `SRD-DYN.md`；API/指标前缀 `srd_dyn_`。
- 配置必须包含：`dt`、积分器、参数集、观测噪声 `R`、过程噪声 `Q`、初值 `x0/P0`。
- 禁止隐式默认：所有影响轨迹的常数必须来自配置或拟合结果，并在输出中回显。
- 输出必须包含：`x_hat`、`P`、`dx/dt`、`Δt`、参数版本、模型版本。
- 兼容性：与原 SRD 只保留“输入检查项/拓扑”的只读兼容；分数不可直接互比。

## 11. v0.0.1 验收标准

以下全部通过，才允许在文档/论文中使用“Systemic Risk Dynamics”：

| 编号 | 验收项 | 通过条件 |
|---|---|---|
| A1 | 独立状态 | 消融 `d` 或 `c` 会改变未来 `s` 轨迹；三状态不可互推 |
| A2 | 非平凡演化 | 在非平衡初值下 `|dx/dt|>0`，且 `\dot s` 随 `d,c` 变化 |
| A3 | 记忆 | 失败撤销后 `d` 按 `δ` 衰减而非归零；半衰期可测 |
| A4 | 反馈 | 固定 `u` 时改变 `d(0)` 会改变 `s(T)`；`η>0` 时出现非线性响应 |
| A5 | 耦合 | `λ>0` 与 `λ=0` 的 `s(T)` 显著不同；邻居塌缩会提前本机恶化 |
| A6 | 滞回/多稳态 | 同一 `s` 在升/降路径上未来轨迹不同；或参数延拓出现鞍结分岔 |
| A7 | 滤波置信 | 后验区间覆盖真实状态的比例接近名义覆盖率（如 95%） |
| A8 | 参数回收 | 合成数据下关键参数估计落在真值置信区间 |
| A9 | 预测技能 | 时间外测试集上优于持久性基线与静态 SRD |
| A10 | 可复现 | 固定种子/`Δt` 下逐位一致；`Δt` 减半误差达标 |
| A11 | 文档一致 | 公式、配置、输出字段与代码一致；无“文档宣称、代码未接线” |

未通过项必须列为已知限制，不得用“工程上可接受”绕过。

## 12. 命名、版本与分叉政策

1. **文件名**：`SRD-DYN.md`；后缀 `-DYN` 不可省略。
2. **版本**：从 `v0.0.1` 起独立语义化版本；**禁止**沿用 `v0.2.x`/`v3.x`。
3. **原 SRD**：`SRD.md` / SRD‑v0.2.3 冻结为对照基线；不在原文件上做“动力学”改写。
4. **代码/产物**：`srd-dyn` 独立模块/命令；不得让旧 `srd` 默认路径悄悄切到新模型。
5. **对外表述**：v0.0.1 通过第 11 节前，只能称“SRD‑DYN 规范草案”，不能称“已实现的系统动力学模型”。
6. **升级**：每次破坏性公式/状态定义变更，主版本 +1；仅参数/实现修正，次版本 +1；文档澄清，补丁版本 +1。

## 附录 B：与原 SRD 的关系

- 原 SRD 的 `PrismScore` 可作为本模型的**观测输入/基线特征**之一，但不再是状态本身；
- 原 SRD 的四态可作为 `s` 的语义标签，但状态转移必须由 `(s,d,c,h)` 的演化决定；
- 原 SRD 的拓扑、检查项、资产关键度可复用为 `A_ij`、`u_i` 的先验；
- 两者分数**不可直接数值比较**，只能比较预测指标。
