## 架构原则

1. **微内核**: kernel 只持接口契约（`TopologyInterface`），实现在地基层 `internal/topology`，kernel 现有文件零改动。
2. **兼容优先**: 现有消费方（comms/SRD/locator）零改动；传播行为在 M2 前不改变。
3. **等待社区**: M0 后里程碑任务友好化（接口/类型已稳定），欢迎协作。

## 与 main 的关系

- **main**: 稳定基线（评估与状态层，v0.2.x 线）。
- **本分支**: 拓扑层研究与演进，不并入 main；成果经评估后以文档/独立模块形式回流。
