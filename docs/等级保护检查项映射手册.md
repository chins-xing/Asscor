# SSAM 2.0 白皮书（第二篇章）：等级保护检查项映射手册

**版本：** 1.8
**日期：** 2026-06-28
**对应白皮书：** SSAM 2.0 算法篇章（第一篇章）

## 概述

本手册为 SSAM 2.0 白皮书的第二篇章，详细列出中国等级保护制度（GB/T 22239-2019，等保2.0）各等级中与安全计算环境、安全通信网络、安全区域边界及安全管理中心相关的控制点，到 SSAM 四个核心域检查项的完整映射。映射范围覆盖等保一级至四级，共涵盖自动化可检测的控制点，不涉及物理安全、人员管理、制度文档等必须人工审查的层面。

每个检查项均包含：等保标准条款编号、等保要求摘要、SSAM 检查项标识、检查方法简述、扣分/加分影响（默认值）。管理员可在配置文件中调整分值。
