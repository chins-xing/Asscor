# ASSCOR 未来规划：v0.2.2 → v1.0.0

**日期**: 2026-08-02 | **当前版本**: v0.2.2 | **目标版本**: v1.0.0

---

## v1.0.0 的定义

v1.0.0 不是"功能做完了"，而是：

1. **概念模型与实现对齐** — 代码行为与白皮书描述一致
2. **架构边界清晰** — 内核不膨胀，层不泄露
3. **生产就绪** — 可观测、可运维、可扩展
4. **API 稳定** — 评估结果格式、插件接口、配置键冻结
5. **有效的测试** — 关键路径覆盖率 ≥ 60%

---

## 不会在 1.0 之前做的事（明确限制范围）

- 不引入 AI/ML 评估引擎（留在 1.x）
- 不做分布式集群（当前单机 + Agent 模式足够）
- 不重写 UI（当前嵌入式 SPA 可用）
- 不支持 Windows Agent（Linux 优先）

---

## 工程哲学（来自第 20 章）

> 架构先于功能。简单优于复杂。分离优于耦合。
> 设计模型而不只是代码。演进而非重写。
> 评估是近似的——分数应提供决策支持，而非替代判断。
