# SRD v2.2 审计报告（2026-10-27）

> 审计对象：SRD **v2.2 / v2.2.1**（`internal/version.SRDVersion = "2.2.1"`）。
> 方法：代码逐条对照 + 运行时复现（VM 910）。**结论按证据分级，不按 changelog 措辞。**

## 0. 一句话结论

**语义层（L1–L5、会话语义、接口级 ACL、角色/区域）已实现且有单测；
但 v2.2.1 声称的"参数可调"在运行时并未生效** —— `[srd]` 配置写进 kernel.ini 后，
启动日志仍显示默认值。数据落库链路（agent → comms → topology registry）**已验证可用**。

## 3. P0 根因分析（A-1）

`Manager.Init` 中：

```go
if cfgObj := kc.GetConfigObj(); cfgObj != nil {
    m.loadConfig(cfgObj)
}
```

运行时 `SRD effective config` 为默认值，说明二选一：

1. `Init` 执行时 `kc.GetConfigObj()` 为 nil（配置尚未注入）——**最可能**；
2. 注入的配置对象不含 `[srd]` 键（已被 v2.2.1 的 `adapterSections` 白名单修复排除，
   且单测 `TestGetExposesSectionKeys` 证明 Parse 后键存在）。

**验证方法（下一步）**：在 `Manager.Init` 里对 `cfgObj` 打一条 info 日志
（类型 + `srd.layered_graph` 读值），重启看是 nil 还是空串——一次即可定因。

## 4. 修复计划（按优先级）

1. **A-1（P0）**：定位 Init 时序；若配置后置，则由 kernel 在配置就绪后调用
   `srd.Manager.ApplyConfig(*config.Config)`（新增导出方法），或在 `Start` 时再读一次。
   验收：kernel.ini 写 `layered_graph=false / transmission=0.42 / max_path_depth=7`，
   重启后日志必须逐项一致；改回默认再验一次。
2. **A-2**：更正 changelog 的"可调"表述为"已接线，启动生效待修（A-1）"。
3. **A-6**：用 v2.2 语义重跑 10 轮随机 ACL 的 ROC，更新 `SRD_CHANGELOG` 里的量化依据。
4. **A-7**：核对 `inferZone` 对私网/管理网的判定，必要时改为可配置区域表。
5. **A-4/A-5**：补非对称 INPUT 场景与 `ct state` 顺序的解析用例；不猜的范围写进文档。

## 5. 审计结论

- **可以对外说**：v2.2 实现了五层语义、会话语义、接口级 ACL 解析、入向 ACL 采集、
  链路事实、区域/角色关键性映射，并有对应单测；
- **不能对外说**：参数已可在生产通过 config.ini 调整（A-1）；
  VLAN 闸门在容器环境生效（A-3）；v2.2 的 ROC 已重新验证（A-6）。


## 6. A-1 修复记录（v2.2.2，2026-10-27）

**诊断证据**（诊断日志，v2.2.1 部署）：

```
msg="SRD config source" cfg_nil=false cfg_type=*srdwrapper.srdConfigAdapter
get_supported=false srd.layered_graph="" effective_layered_graph=true
```

⇒ `kc.GetConfigObj()` 返回的是适配器，`loadConfig` 的类型断言全部落空。

**修复**：`unwrapConfig()` 沿 `GetConfigObj()` 链解包（最多 4 层），再交给 loadConfig。

**修复后现场验证**（kernel.ini 写入 false / 0.42 / 7 / 0.65 / max）：

```
msg="SRD config source" cfg_type=*config.Config get_supported=true srd.layered_graph=false
msg="SRD effective config" layered_graph=false transmission=0.42 max_path_depth=7
    path_decay=0.65 prop_cap=0.25 aggregation=max horizon_days=7
```

→ **A-1 关闭**；v2.2.1 中"不能声称参数可调"的限制正式解除。
剩余 A-3…A-9 仍按 §4 计划推进。
