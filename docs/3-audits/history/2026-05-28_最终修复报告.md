## 详细修复说明

### 1. SPC-001: EPSS因子对数缩放修复

**问题**: EPSS因子使用线性缩放，对高EPSS值区分度不足

**修复前**:
```go
epssFactor = math.Min(1.0, cve.EPSS)
```

**修复后** (符合白皮书规范):
```go
if cve.EPSS > 0 {
    epssFactor = math.Min(1.0, -math.Log(1-cve.EPSS)/5)
}
```

**修复位置**: `internal/kernel/spc.go:849-851`

---

### 2. M-04: WorkerPool排空goroutine修复

**问题**: 超时任务的排空goroutine单独调用了wg.Add(1)，导致WaitGroup计数混乱

**修复前**:
```go
p.wg.Add(1)
go func() {
    defer p.wg.Done()
    select {
    case <-done:
    case <-p.ctx.Done():
    }
}()
```

**修复后**:
```go
// 这里不需要单独的wg.Add，因为外层已经有了，我们只需要等待done即可
select {
case <-done:
case <-p.ctx.Done():
}
```

**修复位置**: `internal/kernel/workerpool.go:96-106`
